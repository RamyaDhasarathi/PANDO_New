# AGENTS.md

## Mission

Build the Hi Pando frontend from the supplied visual reference.

## Read first

Before changing code, read:

1. `README.md`
2. `docs/design.md`
3. `docs/agent.md`
4. `docs/plan.md`

## Source of truth

Visual:
`assets/ui-reference.png`

Mascot:
`assets/pando-mascot.png`

## Rules

- Recreate the reference with real UI.
- Do not use the screenshot as a background.
- Keep Pando central.
- Preserve the four-color palette.
- Prefer real interaction over decorative controls.
- Keep the first milestone frontend-only.
- Do not introduce a backend unless explicitly requested.
- Do not replace complex visual elements with generic UI.
- Run build/lint checks before finishing.

## Definition of done

A user can run:

```bash
npm install
npm run dev
```

and see a working Hi Pando frontend matching the reference design closely.
